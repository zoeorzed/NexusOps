## 可复现的真实对话回归

先按常规方式启动项目，然后执行：

```powershell
docker compose up -d --build
python demo/run_wording_regression.py --output-dir target/wording-regression-新编号
```

脚本需要 Python 标准库和 Docker CLI。它是验收采集工具，业务服务仍是 Java。脚本会调用当前配置的真实模型，产生模型用量，不应放入默认 CI。端口 28218 需空闲；输出目录必须未使用。每次采用新的合成用户/会话、独立知识文件，挂载现有 Skills，关闭模型兜底，完成后删除自己的临时容器，不清空主服务数据。六组十四轮问题固定在 `evaluation/wording-regression-cases.json`，覆盖三类问题各两种问法及追问。

结果文件保留每轮请求、回答、判定理由，另存镜像、源码及用例指纹。脚本成功只说明请求完成和运行前置条件满足，不代表语义正确；必须阅读原始回答核对三类边界。模型返回 true 不能替代内容复核。

## 验证器正反例

`evaluation/wording-verifier-cases.json` 固定了六条正确回答、九条错误回答，包含上轮三条原始回答以及本轮首轮出现的入口建议。使用生产 `AnswerVerifier` 与 `SpringAiLlmGateway`、真实模型、固定合成知识上下文，记录布尔值及理由。固定上下文回放不等于 HTTP 检索链路复测，两类证据分别保存。
